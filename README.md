# Прототип боя на Godot 4

Первая играбельная версия по [требованиям](outputs/game-development-prompt.md). Проект рассчитан на запуск в редакторе Godot 4.7: откройте `project.godot` и запустите главную сцену. При старте появится выбор состава. По умолчанию выбраны четыре героя 1-го уровня и 20 маленьких гоблинов.

## Управление

| Клавиша | Действие |
| --- | --- |
| 1–4 | Выбрать активного героя |
| Q | Удар |
| W | Выстрел лучника |
| E | Заклинание мага или клирика |
| R | Пустой слот |
| A / S | Зелье здоровья / маны |
| Пробел | Следующий активный герой без действия |
| Enter | Открыть или закрыть журнал боя; пока он открыт, бой на паузе |
| Мышь | Выбрать героя или нажать его способность/зелье |
| Esc | Закрыть открытый журнал или перейти к выбору нового боя |

Недоступные слоты и заклинания при нехватке маны не запускают действие и отдых. Нажатие способности без цели запускает действие по правилам документа.

## Структура

- `scenes/main.tscn` и `scripts/main.gd` — экран выбора, поле и интерфейс.
- `scripts/hex_board.gd` — математическая сетка 9 × 10 правильных гексов.
- `scripts/battle_state.gd` — бой, движение, атаки, лечение, появление врагов и условия окончания.
- `scripts/combatant.gd` — состояние отдельного героя или врага.
- `scripts/data_catalog.gd` — загрузка JSON из `outputs/game-data/heroes` и `outputs/game-data/enemies`.
- `assets/` — изображения для поля и интерфейса.

Для изменения свойств героев и врагов редактируйте JSON в соответствующих подпапках. В первой версии опыт не начисляется.

## Состояние изображений

Фон и общий стиль взяты из утверждённого макета. Клирик и лучница в панели изображены людьми. Лучница на поле использует отдельный прозрачный спрайт на основе её портрета. Общие эффекты отряда отложены до следующих версий.
