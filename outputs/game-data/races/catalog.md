# Расовые начальные характеристики

| Раса | Сила / Ловкость / Выносливость / Интеллект | Статус |
| --- | --- | --- |
| [Человек](human.json) | 3 / 3 / 3 / 3 | Утверждено |
| [Гоблин](goblin.json) | 1 / 1 / 1 / 1 | Утверждено |
| [Волк](wolf.json) | 2 / 2 / 2 / 0 | Предложено по утверждённому лесному волку |

Все герои первой версии — люди. Класс не изменяет их характеристики на 1-м уровне. Характеристики героев более высоких уровней отличаются только из-за распределения очков за уровни.

У врагов 1-го уровня характеристики также равны расовой базе без отклонений. Маленький гоблин имеет 1/1/1/1. Бронированный гоблин 2-го уровня получил три очка за уровень: Сила +1, Выносливость +2, итог 2/1/3/1.
